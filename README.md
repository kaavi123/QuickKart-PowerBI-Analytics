# 🛒 QuickKart — E-Commerce Analytics Dashboard

## 📊 Project Overview

QuickKart is an interactive Power BI dashboard designed to analyze
e-commerce sales, customer behavior, product performance and delivery
operations.

## 🎯 Objectives

- Analyze overall revenue and order performance
- Understand customer segments and purchasing behavior
- Analyze product/category sales
- Evaluate delivery performance
- Identify city-wise business trends
- Track cancellations and returns

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- MySQL
- Data Modeling
- Data Visualization


## 📈 Key Metrics

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Delivery Success Rate
- Cancellation Rate
- Return Rate
